# Portrait Sprites

- Naming: `sprites/portraits/<id>/<expression>.png`
- Target frame size: `240x320`
- Palette limit: 32 colors plus transparency
- Do not commit binary art assets to git history
- CI should fetch real art or provide `placeholder.png` as a `10x10` gray transparent stub
- Recommended authoring tool: Aseprite

Portrait ids:

- `ceo_male_01`
- `ceo_male_02`
- `ceo_female_01`
- `employee_zhang_chi`
- `employee_lin_xiaoman`
- `board_chairman`
- `rival_ceo`
- `advisor`

Expressions:

- `neutral`
- `smile`
- `tired`
- `angry`
- `confident`
- `anxious`
- `rip`
